# 박경원 | Kyungwon Park

안녕하세요. 웹 개발을 학습하며 프로젝트를 만들어 가고 있는 박경원입니다.

## 대표 프로젝트

### PHOTO LIFE

사진을 저장하고 공유하는 과정을 주제로 만든 정적 웹 프로젝트입니다.

- 사진 갤러리와 제목 검색
- 사진 추가 UI
- 이미지 상세 보기(라이트박스)
- 좋아요 및 댓글 UI
- 반응형 스타일과 스크롤 애니메이션

## 기술

HTML · CSS · JavaScript · jQuery · Masonry
